## Transformation
Only selected evidence copied; original repository remains private and untouched. Four provenance OS host identifiers are redacted. Numerical evidence, task joins and source licenses remain. Anonymous survey exports preserve all vote values; source identity correspondence is private.
This package is a draft distribution prepared with AI assistance for human-author review, not a backdated reconstruction.

## Critical provenance gaps
